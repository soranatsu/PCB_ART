# 鲸鱼娘双面艺术层示例

以既有鲸鱼娘 v22 板画的四材料艺术层作为输入。正面递信，背面阅读，保留两面不同姿态与完整画幅。尺寸 50 × 100 mm、R3，顶部 18 × 3 mm 胶囊形穿绳槽。

```sh
python scripts/pcb_art.py build examples/deepseek_pass/project.json --out build/deepseek-result
```

从仓库根目录运行。输入沿用原稿 24 px/mm，1200 × 2400 像素，名义采样间距约 0.04167 mm。没有通过放大像素声称恢复更高精度。需要新作或局部矢量重绘时可另用更细网格。

- `F_labels.png`、`B_labels.png` 为单通道标签，0/1/2/3 对应深阻焊、覆铜浅阻焊、白丝印、金。
- `F_materials.png`、`B_materials.png` 为相同标签的可视 RGB 版，便于查看与编辑，可用配置中的 `image` 替换 `labels` 重新输入。
- 两面输入均为正常观看朝向，制造导出只镜像背面一次。
- 输入由原六层艺术图的可见材质关系提取，白丝印具有显示优先级。其下原有隐藏铜不由可见标签反推。
- 默认不做孤岛清理。底铜裕量、丝印避让与槽孔裁切的变化记录在制造差分，细节警示应结合五官、头发、手部和裙褶人工查看。
- 物理顶视 NFC 留空为 `[33.8,69,50,89.5]` mm，对应正常观看背面的左下区。白鲸图案可以保留，功能线圈、芯片、匹配电容及过孔不包含在艺术输入内。

仓库首页展示的是原 v22 工程的完整装配示意，脚本生成的是重新编译的艺术层，不能将其当作完整 NFC 制造包。加入电路按 [NFC 流程](../../references/nfc.md)，生成过孔钻孔文件并复核原理图、原生 DRC 与射频调谐。

`provenance.json` 记录原艺术层哈希、网格和提取语义。角色及图片素材权利归相应权利人，不随 MIT 代码许可转移。
