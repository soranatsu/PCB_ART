# NFC 集成、分析与调试

艺术图案和 NFC 先分别设计，再在同一原生 PCB 中核对。原生网络、芯片引脚和线圈连接负责功能，图像转换器负责装饰材料。任何外观优化都应保留功能对象身份，并重新检查双面铜、开窗和钻孔。

## 版面与天线

优先在不缩小人物和原画幅的情况下安排天线、芯片、匹配电容及手焊空间。左下或右上均可，由构图决定。正文、鲸鱼、主标题及顶部穿绳槽应单独预留，避免先铺满图再强行挖空。

天线有效口径、匝数、线宽、间距、内开口、引线、层间回线与附近金属共同影响耦合。紧凑线圈可以工作，但尺寸本身不能说明扫描距离或成功率。需要更大感应区时重新设计绕组与调谐，不能机械放大旧图后沿用电容。

两面都设置装饰铜留空，范围包括线圈内窗、匝间、芯片及引出区，并向外留裕量。浮置金色图案仍然是导体，不能因为没有电源网络就忽略涡流与耦合。白丝印可以绘制完整鲸鱼或简洁装饰，避开功能焊盘开窗和必要焊接空间。界面上的线圈蓝色代表盖阻焊铜，不需要开窗沉金。

圆角螺旋的每个阶梯连接下一匝，是连续绕组的一部分。将各阶梯接到同一条直线会短接匝间。局部弯折应在不改变连接拓扑与设计间距的条件下优化，不能以外观平直为目的连接不同匝。

## 已复核器件案例

`ST25DV04KC-IE6S3` 为 SO8N、4 Kbit（512 byte）动态 NFC 标签，RF 侧支持 ISO/IEC 15693 / NFC Forum Type 5，能够由读卡场供能。I²C、GPO、能量采集是可选功能。纯 RF 标签无需固件和电池，板上其它电路若有耗电需求须另核算。

按 [ST 数据手册 DS13519 Rev 9，2026-11](https://www.st.com/resource/en/datasheet/st25dv04kc.pdf) 的 SO8N 图 2 核对。

| 引脚 | 名称 | 集成核对 |
|---|---|---|
| 1 | V_EH | 能量采集输出，不用时按实际方案悬空 |
| 2 | AC0 | 天线端 A |
| 3 | AC1 | 天线端 B |
| 4 | VSS | 供电与相关输出参考端，按应用连接 |
| 5 | SDA | I²C 数据，启用 I²C 时需上拉 |
| 6 | SCL | I²C 时钟，启用 I²C 时需上拉 |
| 7 | GPO | SO8N 为开漏输出，启用时需上拉 |
| 8 | VCC | 外部供电输入，与纯 RF 模式分别审查 |

内部 `CTUN` 在 13.56 MHz 下为 26.5 / 28.5 / 30.5 pF（最小/典型/最大），数据手册电气表及条件为准。外部并联调谐电容接在 AC0–AC1 之间，计算只计入一次内部电容。C0G/NP0 适合小 pF 调谐，0603/1608 便于手焊，具体值由天线和装配测量确定。

引脚 1 应结合封装倒角、原厂封装连接图与当前装配方向判断。实物不一定有可见圆点，商城原理图符号的圆点也不保证封装本体有点。原生背面坐标、正常观看方向和手机照片可发生镜像，不能只凭芯片文字方向给所有摆放通用定位。

已有板若将 VCC 与 VSS 连接，必须记录为该纯 RF 电路的特定接法，并核实电气连接。将来增加有源 I²C 接口前须重新设计电源网络，不能向已短接的供电端直接加电。本 skill 不把旧项目接法自动套到新板。

## 原生电路与艺术图层合并

电路模板必须已有正确网络、芯片、焊盘、线圈、引出、过孔和规则，并与艺术板框使用相同顶视坐标、外框及槽孔。提供纯电路模板，移除旧艺术铜和无关覆铜区。无需芯片或 NFC 文字标记时可省略装配丝印，但需保留单独的引脚定位图。

用匹配 KiCad 安装的 Python 运行，系统 Python 通常没有 `pcbnew`。

```sh
/path/to/kicad/python scripts/merge_nfc.py build/demo-result circuit.kicad_pcb --out build/merged-circuit
```

工具核对构建哈希、板框及槽，拒绝未审查覆铜区，确认功能铜加裕量都处于 RF 留空区，再添加艺术绘图。保守包围框检查可拒绝白丝印靠近功能焊盘，需要回到明确 ROI 重构图案。合并前后及保存回读后比较焊盘、网络、走线、过孔、弧线、位置、尺寸和层；失败则不发布制造包。它不自动布线或设计线圈，也不替代原生 ERC/DRC 与射频验证。

合并后使用完整项目的原理图与规则，重跑 ERC、含警告/豁免的 DRC、未连接项和 schematic parity，保存/重填覆铜后从同一状态导出。新目录复制 `.kicad_pro`、`.kicad_dru`，原理图层级需从原工程完整保留，不能假称已匹配。

```sh
kicad-cli pcb drc --severity-all --schematic-parity --exit-code-violations --output drc.txt circuit.kicad_pcb
kicad-cli pcb export gerbers --layers F.Cu,B.Cu,F.Mask,B.Mask,F.SilkS,B.SilkS,Edge.Cuts --output gerber/ circuit.kicad_pcb
kicad-cli pcb export drill --output gerber/ circuit.kicad_pcb
```

命令参数以本机 `--help` 为准。有过孔就必须检查钻孔文件，不可拿七层纯艺术 Gerber 包直接生产。贯穿挂绳槽使用闭合内部板框，不再重复放置镀铜槽焊盘。检查过孔是否按设计盖油，所有开窗是否都对应预期焊盘/金色图案，排查线圈上的孤立露金点。

跨 EDA 导入可能把图形、网桥或开窗转换成不同对象。原生源工程 DRC、嘉立创导入 DRC、直接 Gerber CAM 是不同检查；不能一边导入失真一边为压掉报错放宽规则。分别核对对象和制造输出。

## 零板级寄生基线

`scripts/nfc_analyze.py baseline` 接受显式闭合的 `points_mm` 折线，或 `elements` 线/XY 圆弧序列，全部为三维毫米坐标。闭合路径必须包含芯片/电容端口的理想连接、两层引线和过孔，不能只积分一个未闭合线圈就当总端口电感。输入 `resistive_length_mm` 单独表示实际铜长，不把理想元件闭合段算作铜电阻。

每种圆弧由起点、中点、终点定义。路径连续性、闭合性、零长度和非有限坐标均检查。至少两个逐级减小的分段步长，例如 0.1、0.05、0.025 mm，报告每次电感和末次差值。

模型使用均匀矩形截面的几何平均距离 GMD，计算正则化 Neumann 积分。

\[
L\approx\frac{\mu_0}{4\pi}\sum_{i,j}
\frac{\Delta\ell_i\cdot\Delta\ell_j}
{\sqrt{|r_i-r_j|^2+g^2}},\qquad
C_\mathrm{ext}=\frac{1}{(2\pi f)^2L}-C_\mathrm{chip}-C_\mathrm{board}.
\]

基线令 `C_board=0` 且外部装饰铜缺席，保留指定的芯片电容。均匀截面与正则化属于准静态近似，过孔、焊盘和引线截面差异作近似处理。实际寄生电容、趋肤/邻近电流、金属涡流、介质损耗及非线性芯片加载需额外场模型或测量。分段收敛代表数值一致性，不能当成物理精度。

`examples/compact_10turn.json` 保存一个 0.18 mm 线宽、0.35 mm 节距、10 匝紧凑线圈加跨层回线的匿名几何基准。以电容端闭合、35 µm 铜厚、CTUN=28.5 pF 为条件，历史计算约 2.109 µH，对应零板级寄生下外加 36.8 pF。33 pF 或 27 pF 都不能脱离 Cp、实际电感和加载条件直接判为最佳值。该几何案例的实物扫描尚未验证。

电感、芯片电容及外加电容应有来源、单位和容差。不得为了匹配已选电容而任意补一个 Cp。要评估有寄生情形，应单独标记其来源为提取、测量或显式敏感性假设。局部相邻线对电容之和也不等于整个绕组的端口等效电容。

脚本输出 `Rdc` 与 `ωL/Rdc` 作为 DC 电阻参考。实际 AC 线圈 Q 和装配加载 Q 需要测量或可信损耗模型。频率失谐曲线的相对 dB、VNA 的 S11、芯片端电压、反向散射信号和扫描概率各有定义，不能互相替代。

## 实测调谐

参考 [ST AN2972 Rev 10，2025-09](https://www.st.com/resource/en/application_note/an2972-how-to-design-an-antenna-for-dynamic-nfc-tags-stmicroelectronics.pdf) 的布局与测量章节。使用 VNA 与弱耦合探测小环扫频，逐步增大距离检查峰位是否因探头加载变化。记录仪器校准面、探环、距离、扫频范围、激励、芯片/电容装配与附近金属条件。目标频率应结合器件建议和实际读写表现确定，不机械把全部测试峰拉到 13.56 MHz。

固定 L、CTUN、Cp 且加载近似不变时，可从已测峰位估算下一档外加电容。

\[
C_{\mathrm{new}}=(C_{\mathrm{old}}+C_\mathrm{chip}+C_\mathrm{board})
\left(\frac{f_\mathrm{old}}{f_\mathrm{target}}\right)^2
-C_\mathrm{chip}-C_\mathrm{board}.
\]

先测当前装配，再选相邻 C0G/NP0 值试焊。负的计算电容表示单纯增加并联电容无法达到该目标，需要调整电感/连接或完整匹配方案。调谐与读写分别测试，记录成功次数/总次数、位置、方向、间距和手机型号；具备重复实验后再报告成功率。

## 手焊与启用

1. 先确认引脚定位与焊盘完整性，检查各脚润湿、锡桥和过孔。若返修中芯片翘起，先查焊盘是否剥离和虚焊，暂不据此判断线圈过小。
2. DC 测量要按实际拓扑理解。天线两端通过长铜线相连，呈低电阻可以正常。区分该线圈电阻与邻脚锡桥，必要时拆下芯片/电容分段测量。
3. 在非金属表面、远离其它标签测试。移除磁吸壳或支架，手机顶部感应区对准实际 NFC 区缓慢移动。
4. 先用支持 Type 5 的应用主动读取 UID，例如 [ST25 NFC Tap](https://www.st.com/en/embedded-software/stsw-st25ios001.html)。没有系统网页弹窗不能证明 RF 不工作。
5. UID 可读后按 Type 5 格式初始化 NDEF，再写 URL/文字并回读。核对 CC 文件、容量和字节/块寻址，勿套用 Type 2 的原始块内容。调试阶段保留可写状态，避免永久锁定。
6. 最后在实际保护套、挂绳附件和目标手机上重复读写。电路检查、数值模型、厂家 CAM 和实物测试分别给出结果。
