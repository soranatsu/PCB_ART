# 导出与制造核查

## 输出约定

- 两层艺术板的常用制造图形为 F/B.Cu、F/B.Mask、F/B.SilkS，加闭合板框与必要钻孔。
- 正常观看的背面预览与制造坐标不是同一朝向。约定统一顶视坐标，将背面物理图镜像一次生成制造层；下游不再次镜像。用不对称挂孔及可读文字验证，而不只靠文件名。
- KiCad PCB 原文件、EDA 原生工程、Gerber 制造包是不同交付物。KiCad 文件可作为导入来源但不是嘉立创原生文件；只有实际测试导入后才说已验证导入成功。
- 板厚、油墨颜色、表面处理等不能仅靠预览或 Gerber 保证，下单选项需一致。
- ZIP 只含当前版所需文件，不混旧版同名图层。写清版本、来源、尺寸、极性、背面镜像状态、孔、名义线宽、未验证项。

## 验证层级

1. **源图层**：二值/矢量合法性、统一尺寸及原点、开窗有铜、铜外扩关系、丝印与开窗避让、板边和孔壁间隙。
2. **几何变化**：局部任务在允许区域外图层零差异；整面恢复与指定源版本逐像素/几何一致；板框与孔不应随配色修改。
3. **导出回读**：解析生成的 Gerber 和 PCB，对比实际几何，不只看工具退出码。导出器自己的回读是第一层检查，不是独立验证。
4. **独立解析**：可用已安装的 Gerber 解析器和 PCB 解析器检验层、板框、NPTH 及坐标；验证 ZIP 解压内容与实际检查文件一致。没有独立工具则说明未完成，不能冒充完整 DRC。
5. **EDA/CAM**：如用户要求在线导入，检查导入后的两面与孔位。板厂 CAM 可能修改细丝印或开窗，生产稿再检；不能把本地一致性当板厂审核通过。

几何栅格矩形导出适合二值图，代价是阶梯边缘及对象数量。复用时先确认性能、目标分辨率、软件版本和尺寸。名义线宽不是全路径最小实际宽度；重要细节需局部量测。

## 交付打包纪律

- 构建、局部检查、独立解析全部结束且取得退出状态后，再计算哈希并打包。不能在验证仍运行时生成“已验证”ZIP；验证后发生修改须更新相应检查与归档。
- 交付目录的版本、manifest、说明、预览、检查报告必须描述同一个成品。删去交付说明中已撤销的操作叙述或移出交付主文，不让用户从多段历史中猜哪段有效。
- 完整工程带上必要母稿、局部编辑数据及构建依赖说明；构建不能依赖未随包提供的旧版本目录或临时剪贴板文件。可选的历史差分脚本需明确对照文件要求。
- 主交付给出明确PCB文件、制造ZIP、正常观看双面预览、关键精修局部及简洁下单参数。不要把大量旧辅助图层混入制造ZIP。
- 用户要“商业级/最终成品”时，完成视觉精修和文件核验，并准确报告当前验收阶段；是否量产合格仍依赖生产稿与实物。仅当涉及销售时提示确认角色和素材授权，不把自用精修变成不相关的合规流程。

## 生产稿视觉检查

- 嘴线、眼睛、花体断笔和字腔是否被增粗、删掉或填平。
- 露金区域是否对应正确铜层，细金线有无消失，丝印是否覆盖金色。
- 正反面文字、孔位、整体比例与板框是否正确；不要把生产稿默认底视显示误判成镜像错误。
- 是否额外加入客编、条码、工艺标记；是否影响画面。
- 下单预览、CAM 生产稿和实物色样是不同证据。

艺术画通常值得选确认生产稿。客编影响美观不是功能需求；可建议不加，费用与券条件现场核实。若指定位置需按当前平台规则设置可识别占位文字与下单选项，不能只凭备注承诺。检查规则有变动时查官方说明。
