# 历史案例的复用边界

早期 MyGO 双面板画与后续鲸鱼女仆通行证积累了同一组经验。案例专用尺寸、像素网格、挂孔、字体和版本依赖不应直接作为新项目工具。

- 旧脚本可能引用已认可版本的图层、局部修补、临时生成图和旧导出器。先记录其真实输入输出，保留原始版本，再提取通用逻辑。新项目使用 [pipeline.md](pipeline.md) 的自包含脚本。
- 0.10 mm 嘴线、20 px/mm、特定颜色或挂孔只属于当时的设计。新作品按当前制造能力和可辨识度制定毫米参数，记录量化误差。
- 用户选择原花体后应保留整组轮廓与字腔，局部修复断笔。仅为提亮改变铜层或预览，不隐式加入标题白框或外边框。
- 认可稿、实际制造稿与最新文件可能是不同修订。以当前任务指定的文件、截图及图层差分匹配，不依据文件修改时间猜测。
- 仅凭脚本退出成功、图层差分或 DRC 不能证明人体结构正确、板厂 CAM 已确认或 NFC 实物可用。分别保留各验证阶段证据。

对历史工程做局部修改时，在该工程的新派生版本工作，并保留完整母稿及复现路径。技能不存储个人机器的项目路径、账户或私有素材。
