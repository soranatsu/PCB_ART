# 设计与材料

## 图层关系

| 目标外观 | 铜 | 阻焊开窗 | 白丝印 | 预览层级 |
|---|---|---|---|---|
| 金色金属 | 有，并满足开窗下铜覆盖 | 有 | 避让 | 表面处理色，不按阻焊明暗处理 |
| 覆铜阻焊色 | 有 | 无 | 无 | 同色阻焊中的较浅/较亮档 |
| 无铜阻焊色 | 无 | 无 | 无 | 同色阻焊中的较深/较实档 |
| 白色 | 依据整体设计 | 无 | 有 | 白丝印，不与阻焊色阶混用 |

Mask 通常表示**去掉阻焊的开窗**，不是涂油墨区域。铜与同面开窗重合且下单选择 ENIG 才得到沉金露出区域；只开窗但没有铜不会变金。不要把 Paste 层当作阻焊层。

一面常规阻焊不是可任意指定 RGB 的多色印刷。覆铜/无铜的深浅及方向取决于油墨、厚度、底材、另一面铜和光照；没有工厂样板时不可把“覆铜必定浅很多”当事实。另给低色差预览来暴露层次合并风险，不能称其为真实颜色校准。铜与阻焊层数也不等于视觉颜色数量。

## 覆铜与阻焊的明暗关系

在本 skill 的生产预览约定中，用户观察到的“**有铜更浅**”是正确的默认视觉方向：同一种蓝色、紫色或其他阻焊色中，**有铜且盖阻焊**通常显示为较浅、较亮或更有反光感；**无铜且盖阻焊**显示为较深、较实的阻焊色。它用于表达覆铜造成的光学层次，不代表板厂多印了一种油墨颜色。

必须把以下四种状态分开，不要只按最终 RGB 反推工艺：

1. `Cu ∩ Mask`：有铜、盖阻焊；用同色阻焊的浅档预览。
2. `¬Cu ∩ Mask`：无铜、盖阻焊；用同色阻焊的深档预览。
3. `Cu ∩ ¬Mask`：有铜、阻焊开窗；显示 ENIG 金色，或 OSP 的铜色/暖色，不再显示成浅色阻焊。
4. `¬Cu ∩ ¬Mask`：无铜、无阻焊；是基材或空区，不能当成金色，也不能凭空补铜。

“有铜更浅”是预览和视觉设计规则，不是固定色值或厂家保证。阻焊油墨的遮盖率、厚度、铜面反射、底材、另一面铜、表面处理和光照都会改变实际明暗；实物可能只有轻微差别，个别渲染器甚至会把方向显示得相反。若 3D 预览与经验相反，先检查布尔层关系和渲染器，再决定是否调整示意色，不能通过把整片区域改成亮色来伪造铜层。

建图时先生成铜、阻焊覆盖、阻焊开窗的二值层，再生成同色阻焊的浅/深预览对。蓝色和紫色尤其应保持“同色、不同明度”的关系，不要把覆铜区误做成另一种紫或蓝；沉金和 OSP 只在真实开窗下显示其表面处理色。OSP 的露铜色不宜作为长期稳定的高亮色，需考虑氧化、保存和摩擦后的变化。

嘉立创的工艺说明将 Solder 层定义为阻焊开窗，且同面线路与开窗重合后才形成露铜并按所选表面处理加工；因此本节的浅/深关系只约束预览表达，不改变 PCB/Gerber 层语义。相关入口见 [下单服务指引](https://m.jlc.com/portal/server_guide_4110.html)、[焊盘与铜皮说明](https://www.jlc.com/portal/q1i59058.html) 和 [OSP 工艺说明](https://www.jlc.com/portal/factoryVisitDetails/62511)。

## 建图

默认沉金设计应先确定画面的主体、明暗与少量金色焦点，再生成图层。金色轮廓控制疏密与粗细，避免全局膨胀后过粗、过圆。需要改线宽时以毫米设置，并检查金线之间的阻焊桥及白丝印避让。

ENIG验收针对实际露金集合（铜与开窗交集），不要把全部铜面积当沉金面积。记录开窗下铜覆盖及必要裕量，并以板厂当前能力确定参数；不把历史案例的线宽当通用制造下限。

用户选OSP时，优先用覆阻焊铜与白丝印表达图案，避免依赖露铜长期维持特定颜色。OSP表面保护不是金色镀层；如明确需要露铜装饰，另说明颜色与耐磨需实物验证。不要把OSP预览画成沉金效果。

- 全部图层使用同一画布、尺寸、原点与裁切，不按单层非空包围框独立缩放。
- 首先声明黑白极性。可沿用黑=选中几何的交付 PNG，内部处理白=选中，但在读写处显式转换。
- 用亮度/颜色范围与边缘作为初始选区，最终按语义修正。保存阈值、线宽、原图与修改区域以便复现。
- 对脸和眼睛保护优先。连通域去噪须按物理面积与区域阈值执行，避免误删嘴、眼睛高光、细花体或雪花末端。
- 白色头发高光有碎块时，沿原发束整理为少量连续形状，避免全图闭运算填死眼睛、字腔与口缝。
- 深头发可重分配铜区形成大底色与深色发束。不要简单反相整个区域或给每条浅线套深描边；避免 ROI 直边切进头发、脸和耳朵。逐处看放大图和整图。

## 文字与五官

- 尽可能保留可编辑文字或矢量源。只有栅格字形时，保留原轮廓，而不是猜一个相近字体替换。
- e 的断横笔、o 的字腔等应逐字修复；扩边可能闭合字腔、黏连字母，要看实物尺度。
- 字体粗细判断包含“印上去的线”与“白丝印留出的负形线”。嘴部可通过丝印留空显示下方阻焊；要更暗时评估铜区，不必增加金色或黑色丝印。
- 分辨率换算：像素宽 = 毫米宽 × 像素每毫米。20 px/mm 的网格为 0.05 mm，不能声称精确表达 0.12 mm。优先用可验证矢量/更细局部网格；若采用近似值，说明实际值与量化误差，不静默替换。
- 0.10 mm 是本机案例用户选择的名义细线，不是通用安全下限。普通负形丝印可能需要更大间隙，查当期厂家能力并明确风险；需要保留细线时标为待 CAM/实物验证。

## 挂孔与装饰

- 无电气目的的挂绳孔通常可用 NPTH；孔径、孔边到板边距离依据挂绳与材料选择。3 mm 孔只是案例，不强制套用。
- 孔从板正面看左上，则背面正常观看位置应在右上。铜避让按孔壁计算，而不是从孔中心计算。
- 金色孔环是独立铜与开窗图形，不代表 NPTH 孔壁镀金。不要让孔环铜越过孔边安全间隙。
- 金色面积同时记录双面总面积、单板净面积，以及两个百分比口径：总金面积/单板面积、总金面积/双面面积；不要混用。券或计价口径另核实。
