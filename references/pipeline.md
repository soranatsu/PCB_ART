# 脚本接口与精度

`scripts/pcb_art.py` 将四种材料意图编译为真实铜、阻焊开窗和白丝印。先用 `examples/make_demo.py` 生成一份完整配置，再按此页修改。

## 画布与工艺参数

| 字段 | 单位及含义 |
|---|---|
| `px_per_mm` | 每毫米像素数。40 对应 0.025 mm 网格 |
| `board.width_mm / height_mm` | 毫米画布，两面共用，乘采样率必须为整数 |
| `board.radius_mm` | 外框圆角半径。0 表示直角 |
| `board.thickness_mm` | 名义板厚，默认 1.6 mm，实际下单也需一致 |
| `board.slots` | v0.2 支持零或一个水平胶囊形贯穿槽，字段为 `center_mm / width_mm / height_mm` |
| `nfc_keepouts_mm` | `[x0,y0,x1,y1]` 矩形列表，**统一从板正面看的物理坐标**。同时清除两面艺术铜与开窗 |
| `palette` | sRGB 示意，依次对应深阻焊、覆铜浅阻焊、白、金，必须恰有四种 |

外框是解析线/圆弧，槽是闭合内部 `Edge.Cuts`。各点实际导出到 0.000001 mm 数值精度，源图内容仍受像素网格限制。采样率控制图像转译粒度，不能据此承诺板厂加工精度。

`rules` 的数值均以 mm 或 mm² 表示。示例是设计检查参数，板厂能力与报价需按当前订单核实。

| 字段 | 检查目的 |
|---|---|
| `edge_clearance_mm` | 所有艺术层到板边与槽孔壁的统一留空 |
| `gold_copper_margin_mm` | 金色开窗四周底铜的最小裕量 |
| `silk_to_mask_mm` | 白丝印到实际金色开窗的最小间距 |
| `copper_feature_mm` | 铜/开窗细节开运算的名义直径，仅作警示 |
| `silk_feature_mm` | 白丝印细节开运算的名义直径，仅作警示 |
| `island_area_mm2` | 小孤岛统计阈值，统计本身不删图 |
| `nfc_copper_clearance_mm` | NFC 合并时，功能铜到艺术铜留空区边界的裕量，缺省 0.5 mm。RF 影响范围仍需实测 |

指定的细节直径至少有三个网格单元，否则拒绝构建。重要 0.12 mm 线条应提高分辨率，明确其量化结果，再核对厂家能力。采样过粗时换几何矢量重建，避免声称 0.05 mm 网格精确表达任意细线。

## 每面输入

`faces` 包含 `F`、`B`，至少一面。**两面输入均为正常观看、文字可读朝向**。导出 PCB 时 B 镜像一次。孔槽与 NFC 留空则始终采用共同顶视物理坐标，脚本会转换到背面查看坐标进行布尔运算。

每面二选一使用 `image` 或 `labels`。所有路径相对配置文件所在目录。

- `image` 读取相同尺寸的不透明 RGB。使用 sRGB D65 → CIELAB 的最近四类颜色初始化，不做语义识别。须先在原画中形成四材质方向，不能把复杂彩图直接分色就当最终稿。
- `labels` 读取单通道 PNG，像素仅含 0/1/2/3。其含义依次为深阻焊、覆铜浅阻焊、白丝印、金。
- 不接受隐式缩放、按内容包围框裁切或透明边缘猜色。

可选 `protect` 为区域列表，`cleanup` 与 `overrides` 为有序编辑列表。区域用白色选中/黑色未选的 0/255 掩膜 `mask`，或毫米顶点列表 `polygon_mm`，二选一。每个保护区与清理范围应按脸、发束、手、文字等语义定义，避免矩形边缘切进头发。

```json
{
  "labels": "front_labels.png",
  "protect": [{"mask": "face_eyes_mouth.png"}],
  "cleanup": [{
    "mask": "background_edit_area.png",
    "material": "light",
    "replace_with": "dark",
    "below_area_mm2": 0.02
  }],
  "overrides": [{
    "mask": "forehead_exposed_skin.png",
    "material": "white"
  }, {
    "mask": "title_exact_letters.png",
    "material": "gold"
  }]
}
```

处理顺序为读取/分色 → 清理 → 显式覆盖 → 工艺编译。保护区阻止自动清理，显式覆盖可以按用户意图修复其内部。工艺编译若改变保护区中的材料，会报告错误，需调整构图、规则或明确修改保护范围。

清理采用 8 连通域。仅当完整组件处于编辑区内、面积小于阈值、且不碰保护区时才删除。默认完全不清理。它适合噪点，不能代替续接眉毛、顺发束描线或重建裙褶。

## 工艺编译与差分

`Cu = 浅色区 ∪ 金色区 ∪ 金色所需底铜扩边`。铜避让孔壁、板边及双面 NFC 区。

`Mask = 金色区`，并避让孔壁、板边及双面 NFC 区。白色为开窗，黑色为保留阻焊。

`SilkS = 白色区 − 金色附近避让`，并避让孔壁和板边。NFC 区允许白丝印，其与功能焊盘的关系在原生电路合并阶段复核。

铜的扩边用于开窗底铜裕量，会在金色外沿产生窄的覆铜阻焊区域，不能把它误称为给人物线条整体增粗。扩边与丝印退让使用保守距离阈值，实际量化间距写入报告。默认没有闭运算、全局增粗、轮廓平滑、抖动或随机处理。

`semantic_diff` 标记用户显式编辑与初始分色之差。`manufacturing_diff` 标记最终材料相对编辑标签的变化，含底铜扩边、丝印退让和边缘裁切。任何被裁掉的金色像素有单独计数，需审核是否截断人物、鲸鱼、文字或装饰。被切断的原图应回到构图补齐，不能以“自动避让正常”作为视觉通过理由。

## 检查边界

板边和孔槽对像素单元采用半对角线裕量 `sqrt(2)/(2×ppm)`，保守保证完整像素方格都在允许区。铜与开窗覆盖、跨层间距使用实际像素方格顶点测量。PCB 导出采用相邻扫描行等长区间合并的精确矩形并集，孔洞和负形细线不会被轮廓简化吃掉。

报告的 `opening_loss`、孤岛数与警示图表示待审细节，尖角和曲线末端也可能被标出。**这些统计不能用作全路径最小线宽、工厂可制造性或电气 DRC 的证明。** 需要保留的关键线条单独量测并以真实尺寸查看。纯白围裙中的蓝色负形褶皱也应单独检查。

PCB 回读使用 `sexpdata` 解析，逐层还原矩形并与源图比较。板框及槽的线/圆弧与解析目标对照。该检查与原生 KiCad DRC、独立 Gerber 解析、板厂 CAM、实物测试分别记录。

`gerber` 命令只接受原始构建产物和一致的 manifest。规则错误与原生 DRC 非零阻止打包，不通过降低规则或隐藏警告放行。原生导出后的 Gerber 暂未在脚本内实现独立几何回读，其状态写为 `not_run`。发布前应由目标 CAM 查看器检查两面、开窗和槽孔。

## 规模与复现

40 px/mm 的 50 × 100 mm 图有 800 万像素。脚本以分块方式分色，但距离变换需要完整数组，内存随画布增长。单画布上限为 4000 万像素。复杂母稿会产生较多 PCB 对象，报告记录每层对象数。提高分辨率不能代替减少无意义碎纹。

每次输出独立目录，记录配置、原图/掩膜 SHA-256、编辑差分和检查结果。原图、原生电路和之前版本保持原样。改变已验证图层后，应从该修订重新构建、检查、导出、哈希、打包。
